# Explain mode

Read the accessible model description and accompanying research.
Explain:
- The question the model answers and its scope.
- Inputs, definitions/register, and calculation mechanism.
- Outputs, units, dates, scenario conventions, and uncertainty.
- Published sensitivities and important limitations.

Distinguish observed historical data from assumptions and forecasts.
Distinguish a published sensitivity from a sensitivity you have calculated.
If file inspection is needed, request/use an authorized file path only;
do not execute the package merely to explain it.

Do not infer workbook cells, register keys, formulas, or scenario results from
metadata alone. If documentation is insufficient, list the unknown defaults,
units and input definitions explicitly. Offer to inspect the named authorized
package or have the user attach it where supported; inspection is not execution.
Check metadata/research for obvious scope mismatch before requesting any file.
For quoted figures, distinguish accessible published results from numbers repeated
in an episode or newsletter. Match version, horizon, units and assumptions before
calling a difference a model change; flag anything not verifiable.
Offer Compute only conditionally on the user's request and environment support.
When no Compute ran, answer with explanation, why no rerun, and the useful next
step; do not pad the response with empty results or verification tables.
